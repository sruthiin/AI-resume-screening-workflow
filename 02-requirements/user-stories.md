# User Stories

| ID | User Story | Acceptance Criterion |
|---|---|---|
| US-001 | As a recruiter, I want requirements extracted from a JD so I can compare a candidate consistently. | Only supported requirements are listed. |
| US-002 | As a recruiter, I want candidate skills extracted from a resume so I can avoid manual scanning. | Only explicit skills are reported. |
| US-003 | As a recruiter, I want requirements mapped to evidence so I can review the basis of each match. | Matches cite resume evidence. |
| US-004 | As a recruiter, I want gaps highlighted without assumptions. | Missing evidence is not invented. |
| US-005 | As a recruiter, I want a structured summary. | Evidence, gaps and unknowns are separated. |
| US-006 | As a recruiter, I want AI analysis reviewed before action. | Human review is mandatory. |
| US-007 | As a responsible-AI stakeholder, I want irrelevant personal data excluded. | Irrelevant attributes do not influence job matching. |
