# Scope

## In Scope
- Job requirement extraction
- Resume information extraction
- Relevant skill and experience matching
- Gap identification
- Structured candidate summaries
- Prompt design and optimization
- Hallucination testing
- Bias/fairness testing
- Defect and risk analysis
- Human-in-the-loop control

## Out of Scope
- Autonomous candidate rejection
- AI-only final hiring decisions
- Real candidate data
- Production ATS integration
- Employment verification
- Legal/compliance certification

## Portfolio Boundary
This is an independent portfolio simulation using fictional company information and synthetic candidate data. Any test result must be based on an actual model run and must not be presented as production evidence.
