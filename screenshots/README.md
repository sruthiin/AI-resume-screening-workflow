| 04-v1-output.png | Actual V1 output |
| 05-v2-output.png | Actual V2 output |
| 06-v3-output.png | Actual V3 output |
| 07-match-evidence.png | Actual requirement-to-evidence mapping |

Use filenames that include the Test ID when creating additional screenshots, for example:
`TC-016-v3-hallucination.png`
