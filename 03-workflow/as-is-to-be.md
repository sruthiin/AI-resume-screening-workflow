# AS-IS / TO-BE Workflow

## AS-IS
Resume -> manual extraction -> manual comparison -> summary -> recruiter decision

## TO-BE
Job Description + Resume
-> requirement extraction
-> resume extraction
-> evidence mapping
-> Match / Partial / Gap / Unknown
-> structured summary
-> HUMAN recruiter review
-> final human decision

## Why the Change
The AI is positioned as an evidence-organizing assistant rather than a decision-maker. This creates a clear control boundary: the model can structure information, while a human reviews evidence, context, uncertainty and risks before any employment action.
